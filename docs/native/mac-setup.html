Part 1 · iPhone app (Xcode)

1. Install Xcode

Open the App Store, search Xcode, click Get / Install. It's big; let it finish.

2. Open Xcode once

Open Xcode from Applications. Accept the license. When it asks which platforms to download, tick iOS (the simulator comes with it) and click Download & Install.

If it didn't ask, go to Xcode → Settings → Components and click Get next to iOS.

3. Point the command-line tools at Xcode

This Mac currently uses the small "Command Line Tools" instead of Xcode. Switch it (asks for your Mac password):

sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
sudo xcodebuild -runFirstLaunch

Check: you should see "Xcode 16…" or newer

xcodebuild -version

4. Install XcodeGen

brew install xcodegen

5. Create and open the project

cd ~/code/firstpayday_ios
git pull
xcodegen
open FirstPayday.xcodeproj

6. Run it on the simulator

In Xcode's top bar, choose an iPhone simulator (e.g. iPhone 16) next to "FirstPayday", then press ▶ Run (or ⌘R). The app opens on a simulated iPhone and talks to the real firstpayday.app.

Tip: to see the demo data without an account, choose Product → Scheme → Edit Scheme → Run → Arguments, add -uiTestMock, and run again. Remove it to use your real account.

7. Sign in to Xcode with your Apple ID

Xcode → Settings → Accounts → + → Apple ID. Then click the FirstPayday project (blue icon, left) → target FirstPayday → Signing & Capabilities → pick your Team.

With a free Apple ID ("Personal Team") you can run on your own iPhone, but push notifications need the paid Apple Developer Program ($99/year). If Xcode says the bundle id is taken, add something to it for now (e.g. app.firstpayday.ios.diego).

8. Run it on your iPhone

Plug the iPhone into the Mac with a cable, unlock it and tap Trust. On the iPhone: Settings → Privacy & Security → Developer Mode → On (it restarts). In Xcode, pick your iPhone in the top bar and press ▶ Run.

The first time, the iPhone may say "Untrusted Developer": Settings → General → VPN & Device Management → your Apple ID → Trust.

9. (Optional) Run the tests yourself

cd ~/code/firstpayday_ios
xcodebuild test -scheme FirstPayday -destination 'platform=iOS Simulator,name=iPhone 16'

Ends with "** TEST SUCCEEDED **" (if "iPhone 16" doesn't exist, use a name from xcrun simctl list devices available).

Part 2 · Android app

1. Open Android Studio and install the SDK

Android Studio is already installed. Open it; the Setup Wizard appears. Choose Standard, then Next. On the license screen, accept each license (click each item on the left, then Accept), then Finish. It downloads the SDK to ~/Library/Android/sdk.

If the wizard doesn't appear: More Actions → SDK Manager on the welcome screen.

2. Add the exact pieces the app needs

Settings → Languages & Frameworks → Android SDK (or More Actions → SDK Manager):

SDK Platforms tab: tick Android 15.0 ("VanillaIceCream", API 35).

SDK Tools tab: tick Android SDK Build-Tools, Android SDK Command-line Tools (latest), Android Emulator, Android SDK Platform-Tools. Click Apply → OK.

3. Let Terminal find the SDK and Java

Paste this once; it adds the paths to your shell settings:

cat >> ~/.zshrc <<'EOF'

# Android SDK + Java (First Payday)
export ANDROID_HOME="$HOME/Library/Android/sdk"
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
export PATH="$JAVA_HOME/bin:$ANDROID_HOME/platform-tools:$ANDROID_HOME/emulator:$ANDROID_HOME/cmdline-tools/latest/bin:$PATH"
EOF
source ~/.zshrc

Check: each prints a version, no "not found"

java -version
adb version
sdkmanager --list_installed | head

4. Create an emulator

In Android Studio: More Actions → Virtual Device Manager (or Tools → Device Manager) → + Create Virtual Device → Pixel 8 → Next → system image API 35 (the arm64 one; click the download arrow) → Next → Finish.

5. Open the app project

cd ~/code/firstpayday_android
git pull

In Android Studio: Open → choose the folder ~/code/firstpayday_android. Wait for the "Gradle sync" bar at the bottom to finish (the first time downloads a lot).

6. Run it

Top bar: pick the Pixel 8 emulator, then press the green ▶ Run 'app'. The app opens and talks to the real firstpayday.app.

7. Run it on your Android phone

On the phone: Settings → About phone → tap Build number 7 times (Developer options on). Then Settings → System → Developer options → USB debugging → On. Plug it in, tap Allow on the phone, pick it in Android Studio's top bar, press ▶.

8. (Optional) Build and test from Terminal

cd ~/code/firstpayday_android
./gradlew testDebugUnitTest assembleDebug

Ends with "BUILD SUCCESSFUL". With the emulator open, the screen tests: ./gradlew connectedDebugAndroidTest
